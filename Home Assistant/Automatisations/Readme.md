# Automatisations Karotz

Ce dossier contient les fichiers de configuration pour les automatisations de votre Karotz dans Home Assistant.

## Configuration des Automatisations

Les automatisations permettent de :
- Réagir aux événements RFID
- Contrôler automatiquement les oreilles et les LED
- Gérer les modes veille/réveil
- Déclencher des actions personnalisées
- Annoncer l'heure toutes les heures entre 7h et 20h
- Comportement du Karotz en fonction de la météo

## Installation

1. Copiez le contenu des fichiers à la fin du fichier "openkarotz.yaml"
2. Adaptez les entités et les actions selon votre configuration
3. Redémarrez Home Assistant (le rechargement rapide suffit)

## Personnalisation

Pour personnaliser les automatisations :
1. Ouvrez le fichier d'automatisation
2. Modifiez les conditions et les actions
3. Ajustez les paramètres selon vos besoins
4. Sauvegardez et redémarrez

## Dépannage

Si une automatisation ne fonctionne pas :
1. Vérifiez les logs de Home Assistant
2. Assurez-vous que les entités existent
3. Vérifiez les conditions et les actions
4. Testez manuellement les actions

## Bonnes Pratiques

- Documentez vos automatisations
- Testez avant de déployer
- Faites des sauvegardes régulières
- Utilisez des noms explicites pour les entités
